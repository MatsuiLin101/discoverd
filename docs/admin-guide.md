# 後台管理操作說明

## 輪播圖管理（首頁 Hero）

### 入口

後台側邊欄 → **前台管理 → 輪播圖管理**（`/admin/hero-banners`）

### 功能說明

| 功能 | 說明 |
|------|------|
| 新增 | 上傳一張圖片並填入標題，圖片儲存於 Cloudinary |
| 編輯 | 可修改標題，或重新上傳替換圖片 |
| 刪除 | 同步刪除 Cloudinary 上的圖片資源 |
| 排序 | 拖曳列表中的 ⠿ 圖示即可調整前台顯示順序 |

### 備用圖片（Fallback）

若後台**尚未設定任何輪播圖**，前台會自動顯示以下三張靜態備用圖片：

```
web/public/images/hero/hero-1.jpg
web/public/images/hero/hero-2.jpg
web/public/images/hero/hero-3.jpg
```

> 請在正式上線前將這三個檔案放到對應路徑。

---

### 輪播圖片規格建議

| 項目 | 建議值 |
|------|--------|
| 尺寸 | **1920 × 900 px** |
| 長寬比 | 約 **16:7.5**（介於 16:9 與 2:1 之間） |
| 格式 | JPG |
| 檔案大小 | 壓縮後 **500 KB 以內**（Cloudinary 會自動進一步優化） |
| 構圖重點 | 主視覺置中偏上，避免將重要元素放在四個角落 |

**構圖說明：** 桌機顯示高度約為 `視窗高度 - 84px`，手機則更接近方形比例。由於兩種裝置都以 `object-fit: cover` 裁切，左右兩側與底部在手機上較容易被裁掉，因此主題建議放在**畫面中央偏上**的位置。
