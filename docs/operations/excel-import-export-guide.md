# Excel 匯入／匯出操作說明

> 對象：後台管理人員。適用模組：**地區、標籤、旅遊方案**。
> 本文為給使用者（甲方）的操作指南，用語以實務操作為主。

---

## 一、基本流程（三個模組共通）

每個管理頁面（地區／標籤／旅遊方案）右上角都有一組按鈕：**匯出 Excel ／ 下載範本 ／ 匯入 Excel**。

建議流程：

1. 點 **匯出 Excel**，下載目前的資料。
2. 用 Excel 編輯（修改內容，或新增資料列）。
3. 點 **匯入 Excel** 上傳檔案。
4. 系統會先顯示**預覽**：會新增幾筆、修改幾筆、跳過幾筆，以及逐列的內容與備註。
5. **確認無誤後，再按「確定匯入」，資料才會真正寫入。**

> 不熟悉格式時，可先點 **下載範本** 參考欄位。

### 權限

| 動作 | 管理員 | 一般員工 |
|------|:------:|:--------:|
| 匯出 Excel／下載範本 | ✅ | ✅ |
| 匯入 Excel | ✅ | ❌（看不到匯入） |

### 匯入是「先預覽、再確認」

匯入分兩段：上傳後只會**試算並顯示預覽**，不會馬上改資料；一定要再按「確定匯入」才會寫入。所以可以放心先試上傳、看結果。

---

## 二、⚠️ 最重要的共通規則：代碼欄請勿手動修改

檔案中的這些「代碼」欄位——**主分類代碼、次分類代碼、ProductID（商品編號）**——都是**系統自動編號、且一旦配發就固定不變**。

- 它們的用途是讓系統**辨識這一列對應到哪一筆既有資料**（拿代碼去比對），**不是**讓您手動設定編號。
- **請勿手動修改代碼欄。** 若把代碼改成不存在的號碼，系統會把該列當成「新資料」處理，甚至可能因名稱重複而匯入失敗。
- 要新增資料時，把代碼欄**留空**即可，系統會自動配號。

---

## 三、旅遊方案（最常用）

匯出的檔案會**依主分類分成不同分頁（工作表）**，例如「101日本」「102台灣」，每個分頁內的行程依商品編號排序，方便查找。匯入時系統會讀取**所有分頁**。

**欄位**：ProductID、主分類、次分類、標籤、行程名稱、價格、行程簡介、發布(Y/N)

### ProductID（商品編號）決定新增或修改

| 該列的 ProductID | 系統處理方式 |
|------------------|--------------|
| **有編號** | 視為**修改**那一筆既有行程 |
| **空白（沒編號）** | 視為**新增**，系統自動配一個新編號 |

- 想**修改**某筆行程 → 直接改那一列的內容（**保留它的編號**）再匯入。
- 想**新增**行程 → 新增一列，**ProductID 欄留空**。

### 其他欄位規則

| 欄位 | 說明 |
|------|------|
| 主分類／次分類 | 直接填**名稱**；系統裡沒有的會**自動建立**。 |
| 標籤 | 多個標籤用**半形逗號「,」**分隔（例：`免小費,中華航空`）；不存在的自動建立。 |
| 價格 | 填**純數字**（不用打千分位逗號）。**填 `0` → 前台顯示「客製化報價」。** |
| 發布(Y/N) | 填 `Y` 或 `N`。**預設為發布**；只有填 `N` 才會變成未發布（前台不顯示）。 |
| 行程簡介 | 可換行、可空白。 |

### 疑似重複提醒

若匯入的列**沒有編號、但主分類／次分類／行程名稱和現有行程完全一樣**，預覽會標示 **⚠️ 疑似重複**，提醒您確認。您仍可選擇匯入（會當成一筆新行程並配新編號）。

### 預覽可切換分頁、勾選要匯入的列

匯入預覽畫面可以**依分頁切換檢視**，並**勾選**要匯入哪些列——不必整批全部匯入。

---

## 四、地區

- 一張表同時含**主分類**與**次分類**兩層。
- 可**新增**主分類/次分類、**改名稱**、**改 SEO 欄位**。
- 辨識方式：可用代碼**或**名稱（代碼留空時用名稱比對）。一般使用者可完全不碰代碼欄。
- **代碼欄請勿手動修改**（見第二節）。

---

## 五、標籤

- 只有一欄：**標籤名稱**。
- 匯入只會**新增不存在的標籤**；已存在的自動略過（標籤只有名稱，沒有「修改」的動作）。
- 適合一次批次建立多個標籤。

---

## 六、注意事項

- **縮圖、行程內容檔（PDF／圖片）不在 Excel 裡**，請於匯入後到後台各行程頁面補上。
- 同一個檔案重複上傳，系統會提醒「這個檔案先前匯入過」。
- 匯入一律**先預覽、再確認**，不會直接動到資料。

---

## 七、建議測試項目

1. 匯出一份旅遊方案，檢視格式與分頁。
2. 改一筆行程的價格或簡介 → 匯入 → 確認有更新。
3. 新增一列（**不填編號**）→ 匯入 → 確認有新增。
4. 把某筆價格填 `0` → 確認前台顯示「客製化報價」。
5. 發布欄填 `N` → 確認該行程前台看不到。
6. 標籤：匯入含新舊標籤的檔案 → 確認新的有加、舊的被略過。
